# Penkin AI Analytics: публичные документы

Русскоязычный информационный сайт приложения.

- [Политика конфиденциальности](privacy/)
- [Пользовательское соглашение](terms/)

В репозитории только статические страницы и оформление. Сайт не содержит API-сервера, данных Instagram, токенов или базы приложения.

Публикация: GitHub Pages, ветка main, корень репозитория, HTTPS. ".nojekyll" отключает обработку Jekyll.

Страница data-deletion является инструкцией для человека. Она не реализует автоматический callback удаления данных.
